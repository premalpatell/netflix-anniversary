**For every logo:**
- Aspect ratio 16:9, the largest size Flow offers.
- Solid pure black background. I remove it, so don't ask for a transparent one.
- If a result misspells the title, regenerate. The exact spelling matters.
- If Flow refuses because a title is a real show name, keep the style and add “inspired lettering, original design” at the end.
