# Personalised logo prompts (round 2)

These replace the first round. Every logo keeps its show's lettering style, but adds small details from that day: the place, the food, the outfit, the objects in your photos. There are still no people in them.

**How to use**

- Use the same settings as before: **16:9** and a **plain black background**. Check the spelling of every logo.
- Save each one under the file name shown (for example `p-stranger-things.png`), or at least keep the title somewhere in the file name so I can match it.
- Upload them to a new Drive folder called **Site Art 2**.
- If Flow refuses a prompt or the result gets too busy, drop the "Personal details" sentence and try again. The title text must stay the biggest and clearest thing in the image.
- You don't have to redo them all. Any logo you skip keeps its round-1 version.
